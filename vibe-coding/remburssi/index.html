Two different questions. The first results block is about the bank: will the presentation be refused? The second is about the deal: does the trade term fit the credit, the transport and the insurance? Banks deal with documents, not the sale contract (UCP 600 Art. 4), so an Incoterms mismatch only becomes a discrepancy when it shows up as a conflict in the documents or the credit's own terms.

Scope. An educational tool, not a substitute for a trained document examiner. It checks only the fields above against the default rules. The credit's own conditions can modify or exclude these articles. Banks have up to five banking days following the day of presentation to examine documents (Art. 14(b)).
